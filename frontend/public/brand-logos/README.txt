Drop car-brand logo image files here to have them appear automatically on
the parts-catalog kiosk page (/catalog), no code changes needed.

Naming: lowercase, spaces/dashes collapsed to a single dash, .png extension.
Examples:
  Toyota          -> toyota.png
  Mercedes-Benz   -> mercedes-benz.png
  Range Rover     -> range-rover.png

If a brand's file is missing, the kiosk page falls back to a colored badge
with the brand's initials, so nothing breaks while logos are being added.

Recommended size: roughly square, at least 200x200px, transparent background
if possible (the tile shows it on a white circle).
